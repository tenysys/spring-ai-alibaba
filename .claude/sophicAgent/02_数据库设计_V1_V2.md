# SophicAgent 数据库设计（V1 / V2）

## 1. 统一建模约定
- 多租户：核心业务表统一 `workspace_id`。
- 主键：统一 `id bigint unsigned auto_increment`。
- 业务键：统一使用 `xxx_id` / `xxx_code`。
- 状态：统一使用 `status`，需要启停时补充 `enabled`。
- 时间：统一使用 `gmt_create`、`gmt_modified`，运行类记录可补充 `gmt_start`、`gmt_end`。
- 复杂配置：优先使用 `json` 字段承载快照、策略、DSL、规则和扩展元数据。
- 命名：表名前缀统一为 `sophic_agent_`。

## 5. 状态机建议
- 资源：`0=DELETED,1=DRAFT,2=PUBLISHED,3=ARCHIVED`
- 任务：`1=QUEUED,2=RUNNING,3=SUCCESS,4=FAILED,5=CANCELED,6=TIMEOUT`
- 步骤：`1=PENDING,2=RUNNING,3=SUCCESS,4=FAILED,5=SKIPPED`
- 发布：`1=DRAFT,2=PUBLISHED,3=OFFLINE,4=DELETED`
- 评测任务：`1=CREATED,2=RUNNING,3=FINISHED,4=FAILED`

## 7. 表说明与关键属性说明

### 7.1 身份权限域

#### `sophic_agent_account`
- 表说明：账号主表。
- 关键属性：
- `account_id`：账号业务标识。
- `username`：登录用户名。
- `email` / `mobile`：联系方式。
- `password_hash`：密码摘要。
- `nickname` / `avatar`：展示信息。
- `status`：账号状态。
- `gmt_last_login`：最后登录时间。

#### `sophic_agent_workspace`
- 表说明：工作空间表，用于多租户隔离。
- 关键属性：
- `workspace_id`：工作空间业务标识。
- `name`：工作空间名称。
- `description`：描述。
- `owner_account_id`：负责人账号。
- `config`：工作空间配置。
- `status`：工作空间状态。

#### `sophic_agent_api_key`
- 表说明：API 调用凭证。
- 关键属性：
- `workspace_id`：所属工作空间。
- `account_id`：所属账号。
- `api_key`：访问密钥。
- `description`：凭证说明。
- `expired_at`：过期时间。
- `status`：启用状态。

#### `sophic_agent_role`
- 表说明：角色定义。
- 关键属性：
- `workspace_id`：所属工作空间。
- `role_code`：角色编码。
- `role_name`：角色名称。
- `status`：角色状态。

#### `sophic_agent_permission`
- 表说明：权限点定义。
- 关键属性：
- `perm_code`：权限编码。
- `perm_name`：权限名称。
- `resource_type`：资源类型。
- `action`：动作类型。

#### `sophic_agent_role_permission`
- 表说明：角色与权限点映射关系。
- 关键属性：
- `workspace_id`：工作空间。
- `role_code`：角色编码。
- `perm_code`：权限编码。

#### `sophic_agent_account_role`
- 表说明：账号与角色映射关系。
- 关键属性：
- `workspace_id`：工作空间。
- `account_id`：账号标识。
- `role_code`：角色编码。

### 7.2 应用与设计器域

#### `sophic_agent_application`
- 表说明：应用资产主表，参考 `spring-ai-alibaba-admin` 的 `application` 表，统一承载 `agent` 和 `workflow` 两类应用。
- 关键属性：
- `agent_id`：应用业务标识。
- `agent_code`：应用编码。
- `name`：应用名称。
- `description`：应用说明。
- `icon`：图标。
- `source`：来源，如 `console` / `import` / `builtin`。
- `type`：应用类型，`agent` / `workflow`。
- `agent_scope`：应用范围，区分通用/场景化/模板内置。
- `scene_type`：业务场景类型。
- `latest_version`：最新版本号。
- `published_version`：当前发布版本号。
- `tags`：标签。
- `status`：应用状态。

#### `sophic_agent_application_version`
- 表说明：应用版本表，参考 `spring-ai-alibaba-admin` 的 `application_version` 表，V1 通过版本快照统一承载 Agent 和 Workflow 配置。
- 关键属性：
- `agent_id`：所属应用。
- `version`：版本号。
- `version_desc`：版本说明。
- `config_snapshot`：完整应用配置快照，V1 核心字段。
- `runtime_config`：运行配置。
- `input_schema` / `output_schema`：入参和出参定义。
- `dsl_schema`：导出 DSL 快照。
- `change_log`：变更摘要。
- `base_version`：派生来源版本。
- `status`：版本状态。

#### `sophic_agent_agent_schema`
- 表说明：Agent 特有结构化定义表，参考 `spring-ai-alibaba-admin` 的 `agent_schema` 表，仅在 `type=agent` 时使用。
- 关键属性：
- `agent_schema_id`：schema 业务标识。
- `agent_id`：所属应用。
- `version`：所属版本。
- `name`：agent 名称。
- `description`：说明。
- `agent_type`：Agent 类型，如 `ReactAgent`、`ParallelAgent`、`SequentialAgent`。
- `instruction`：系统指令。
- `input_keys` / `output_key`：输入输出定义。
- `handle_config`：执行句柄配置。
- `sub_agents`：子 Agent 配置。
- `yaml_schema`：导出的 YAML 配置。
- `enabled`：启用状态。
- `status`：结构定义状态。

#### `sophic_agent_application_binding`
- 表说明：应用挂载组件表，对标 `spring-ai-alibaba-admin` 的 `application_component`，用于承载“应用上挂了什么组件”。
- 关键属性：
- `binding_id`：绑定业务标识。
- `agent_id`：应用标识。
- `agent_version`：应用版本。
- `resource_type`：资源类型，如模型、知识库、工具、MCP 服务、数据源、记忆库、Agent、Workflow。
- `resource_id`：资源业务标识。
- `resource_name`：资源名称快照。
- `binding_source`：绑定来源。
- `sort_no`：排序。
- `enabled`：启用状态。
- `binding_config`：组件级绑定配置。
- `status`：绑定状态。

#### `sophic_agent_application_binding_item`
- 表说明：挂载组件详细信息表，用于承载组件内部选中的细粒度对象，对应 admin 中 `reference` 的细粒度语义。
- 关键属性：
- `binding_id`：所属绑定关系。
- `item_type`：明细类型，如 MCP 工具、表、字段、语义模型、文档、参数映射等。
- `item_id`：明细项标识。
- `item_name`：名称。
- `item_path`：逻辑路径，如表字段路径、工具路径。
- `item_config`：明细配置。
- `sort_no`：排序。
- `status`：明细状态。

#### `sophic_agent_high_code_service`
- 表说明：高代码服务主表。
- 关键属性：
- `service_id`：服务业务标识。
- `service_code`：服务编码。
- `name`：服务名称。
- `service_type`：服务类型，如 Java/Python。
- `runtime_type`：运行框架类型。
- `owner_account_id`：负责人。
- `permission_scope`：权限范围。
- `latest_version`：最新版本。
- `tags`：标签。
- `status`：状态。

#### `sophic_agent_high_code_service_version`
- 表说明：高代码服务版本表。
- 关键属性：
- `service_id`：所属服务。
- `version`：版本号。
- `package_type`：制品类型，如 `JAR` / `DOCKER`。
- `package_uri`：制品地址。
- `deploy_config`：部署配置。
- `input_schema` / `output_schema`：输入输出协议。
- `change_log`：版本变更说明。
- `status`：状态。

#### `sophic_agent_model_provider`
- 表说明：模型提供方。
- 关键属性：
- `provider_code`：供应商编码。
- `name`：名称。
- `protocol`：接入协议。
- `credential`：认证配置。
- `status`：状态。

#### `sophic_agent_model`
- 表说明：模型定义表。
- 关键属性：
- `model_code`：模型编码。
- `provider_code`：所属供应商。
- `model_name`：模型名称。
- `model_type`：模型类型，如对话、嵌入、重排。
- `mode`：调用模式。
- `model_params`：模型参数。
- `status`：状态。

#### 应用与设计器域补充说明
- V1 不再优先拆分 `workflow_definition / workflow_version / workflow_node / workflow_edge` 四张表。
- `type=workflow` 的流程定义、节点、边、画布、调试参数统一存放在 `sophic_agent_application_version.config_snapshot` 中。
- 当后续出现节点级复用、节点级审计、节点级差异分析等强诉求时，再演进独立工作流结构表。
