# SophicAgent 数据库设计（V1 / V2）

## 1. 统一建模约定
- 多租户：核心业务表统一 `workspace_id`。
- 主键：`id bigint unsigned auto_increment`。
- 业务键：`xxx_id` / `xxx_code`。
- 状态：统一 `status`，需要开关时补 `enabled`。
- 时间：统一 `gmt_create`、`gmt_modified`。
- 复杂配置：优先 `json` 字段（快照、策略、DSL）。

## 4. 关键关系
- `sa_agent` 1-N `sa_agent_version`
- `sa_workflow_definition` 1-N `sa_workflow_version`
- `sa_workflow_version` 1-N `sa_workflow_node`
- `sa_workflow_version` 1-N `sa_workflow_edge`
- `sa_task` 1-N `sa_execution_plan`
- `sa_execution_plan` 1-N `sa_execution_step`
- `sa_knowledge_base` 1-N `sa_knowledge_document`
- `sa_knowledge_document` 1-N `sa_knowledge_chunk`
- `sa_tool` 1-N `sa_tool_version`
- `sa_fault_record` 1-N `sa_fault_process_record`

## 5. 状态机建议
- 资源：`0=DELETED,1=DRAFT,2=PUBLISHED,3=ARCHIVED`
- 任务：`1=QUEUED,2=RUNNING,3=SUCCESS,4=FAILED,5=CANCELED,6=TIMEOUT`
- 步骤：`1=PENDING,2=RUNNING,3=SUCCESS,4=FAILED,5=SKIPPED`

## 6. 索引建议（核心）
- `sa_task(workspace_id, agent_id, status, gmt_create)`
- `sa_execution_step(task_id, step_no)`
- `sa_invoke_log(workspace_id, task_id, gmt_create)`
- `sa_runtime_metric(workspace_id, metric_name, collect_time)`
- `sa_knowledge_document(workspace_id, kb_id, index_status, status)`
