# SophicAgent 功能设计与复用映射

## 1. 当前功能设计（依据系统设计说明书 4~8 章，并结合产品功能补充）

### 1.1 智能体管理子系统
#### 应用资产管理
- 平台应用统一分为 `agent` 和 `workflow` 两种类型。
- 支持应用条件筛选、排序、收藏、最近访问和反馈入口。
- 支持按版本导出智能体 DSL，作为迁移、复用和归档载体。

#### 通用智能体管理
- 作为应用资产管理的一类标准化应用，支持分类、检索、排序、详情查看、定义加载和版本查询。
- 支持查看版本差异，包括入参、出参和功能变更说明。
- 支持从详情页直接进入运行中心使用，或复制到设计器中二次编辑。

#### 专用智能体管理
- 作为应用资产管理的一类场景化应用，支持按业务场景管理专用智能体，如问数、报告、运维、设备管控、调度辅助等。
- 支持加载运行配置、展示所引用的通用能力和依赖资源。
- 支持场景化分类、标签筛选和运行参数预览。

#### 高代码服务管理
- 管理 Java/Python 实现的高代码服务。
- 支持服务注册、信息修改、版本管理、下载和删除。
- 版本形态支持 `jar` 和 `docker`，并区分管理员、所有者等操作权限。

### 1.2 设计器子系统
#### 设计器列表与应用创建
- 支持设计器列表筛选、批量删除、标签管理和权限设置。
- 支持创建智能体和工作流两类应用。
- 工作流采用 Dify 风格流程构建模式；智能体基于模板创建，支持通用模板和平台内置高代码模板。

#### 工作流编排
- 支持顺序、分支、并发、重试、回退等流程模式。
- 支持画布拖拽、节点连线、节点参数配置、流程校验和版本保存。
- 产出可供运行时装载执行的流程定义。

#### 智能体配置
- 支持基础信息、模型策略、工具绑定、知识源绑定、记忆策略和 I/O 参数配置与校验。
- 模型配置支持 `temperature`、`topK`、`topP`、最大 token 数、思考开关等参数。
- 提示词配置支持自定义变量和 AI 优化。
- 知识配置支持绑定 Dify 知识库。
- 工具配置支持绑定 MCP 服务、智能体、工作流和数据源，并细化到具体 MCP 工具、表、概念和属性。
- 记忆配置支持短期记忆轮数和长期记忆规则绑定。
- 回复配置支持无法解答时返回固定内容。

#### 发布、过滤与调试
- 支持 API 调用方式配置。
- 支持发布为应用或发布为工具，分别进入智能体管理界面或能力组件系统。
- 支持数据干预和规则干预；数据干预可基于已有问答指定标准回复，规则干预支持敏感词正则替换。
- 支持调试日志、运行日志和全流程跟踪。
- 支持监测指标展示，包括会话数、使用人数、失败次数和首包延时。

### 1.3 运行时子系统
#### 环境感知
- 接收用户请求、外部事件、告警事件、实时数据变化等触发信息。
- 解析上下文、执行授权校验，并路由到目标智能体或工作流。

#### 智能决策
- 基于任务上下文生成执行计划。
- 选择候选工具、知识检索路径和执行策略。
- 对高风险动作进行识别和校验，必要时转人工确认。

#### 任务执行
- 支持执行计划和步骤执行，调用工具、工作流、知识检索和模型能力。
- 支持中间状态保存、异常恢复和结果汇总。
- 支持流程跟踪、步骤回放和会话级执行记录查看。

#### 协同调度与运行控制
- 支持任务提交、优先级调度、资源分配、并发控制、任务排队、队列查询和任务取消。
- 支持平台应用、工作流和高代码服务的统一运行入口。
- 高代码服务支持启动、停止、重启和部署记录查看。

### 1.4 能力组件子系统
#### 工作流引擎
- 支持流程装载、执行、挂起、恢复、终止、状态查询和版本发布。
- 为设计器编排结果提供稳定的确定性执行引擎。

#### 知识库能力
- 支持知识导入、索引、检索、权限校验和 RAG/GraphRAG 检索。
- 嵌入 Dify 知识库管理界面，支持知识库创建、构建和分片检索测试。
- 支持知识源统一纳管和检索效果验证。

#### 工具中心
- 统一管理 MCP 服务、智能体工具和工作流工具。
- 支持工具注册、发现、调试、部署、调用和 REST 转 MCP 适配。
- 设计器中发布的智能体/工作流可在工具中心继续启停、删除和授权，并作为其他智能体的工具复用。

#### MCP 服务管理
- 支持获取 Nacos 中配置的 MCP 服务记录。
- 支持将常规 RESTful 服务注册为 MCP 服务。
- 支持启用、删除、信息修改、运行控制、写权限设置、标签管理、工具入参/出参/描述配置和服务实例列表展示。

#### 数据源管理
- 支持商用库、统一模型和 Sophic 数据源的配置、筛选、排序、搜索和概览统计。
- 支持语义配置，允许用户自定义属性说明；每份数据源对应唯一语义配置，支持更新、导入导出和 AI 批量生成。
- 支持逻辑外键配置，面向商用库维护表间关联关系、字段映射和关系描述。

#### 记忆管理
- 支持短期记忆、长期记忆和工作记忆的读写、恢复和清理。
- 长期记忆支持记忆库管理、记忆日志、记忆规则设置和记忆检索。
- 每个记忆库绑定一套规则，应用可绑定指定记忆库。
- 支持记忆片段、记忆实体、命中率测试和相似度召回验证。

### 1.5 框架治理子系统
#### 运维监控
- 采集运行指标、查询运行状态、资源使用、告警和历史趋势。
- 支持按应用维度查看日志和统计指标，展示应用总量、总调用次数、总失败次数、平均调用时长和平均首包延时。

#### 日志审计与统计
- 支持调用日志、审计事件、调用链追踪和审计归档。
- 支持按用户、业务、模型、工具、时间等维度统计并生成报表。

#### 权限与安全
- 支持权限校验、数据访问策略、脱敏、高危动作拦截和角色授权。
- 提供用户、角色和权限管理。
- 商店、设计中心、能力中心支持读写控制；框架治理界面默认仅管理员可访问。

#### 异常容错、高并发与高可用
- 支持异常处理、重试、切换备用模型、恢复和故障处理查询。
- 支持限流、排队、并发配额和超载拒绝。
- 支持健康检查、主备切换、故障接管和服务恢复。

#### 模型、发布与集成管理
- 模型管理支持对话、嵌入、索引、重排等模型配置，支持启停控制、运行参数配置和连接测试。
- 发布管理统一管理应用、工具和高代码的发布版本，支持查看版本详情并删除已发布版本。
- 部署集成支持部署计划、配置加载/更新、外部系统集成和接入点注册。

#### 评估管理
- 支持效果评估、性能评估和评测集管理。
- 自动评测支持基于知识库自动构造问题和参考答案，并对输出准确性自动打分，支持评测任务管理。
- 手动评测支持人工构造单轮或多轮对话并进行结果打分。
- 评测集管理维护一问一答测试数据集，用于与应用输出结果做比较。
- 性能评估支持对应用和工具进行压测，并管理压测任务。

### 1.6 人机界面与前端功能补充
#### 整体布局与导航
- 采用“顶部全局导航 + 左侧功能菜单 + 中央工作区 + 右侧详情/配置抽屉”的管理台布局。
- 主工作台作为统一入口，下钻至智能体详情页、工作流设计页、运行控制台、能力资产页和治理监控页。
- 支持面包屑导航、标签页切换、状态标签、版本切换、收藏/最近访问。

#### 全局交互对象
- 支持全局搜索、批量操作工具栏、右键快捷操作和操作确认弹窗。
- 支持从详情页返回列表或跳转到关联配置页面。

#### 分域界面功能
- 智能体管理界面支持列表、详情、版本、反馈、复制、导出和运行入口。
- 设计器界面支持画布编排、配置面板、调试日志、发布、过滤和监测。
- 运行时界面支持任务提交、会话管理、执行计划展示、步骤跟踪、暂停、恢复、取消和高风险确认。
- 能力组件界面支持知识库、工具、数据源、记忆等资产的统一管理、检索测试和权限配置。
- 治理运维界面支持监控大盘、日志审计、统计报表、模型管理、评估管理、发布管理和权限管理。

## 2. 复用映射（基于 spring-ai-alibaba-admin）

| SophicAgent 模块 | 可复用能力 | spring-ai-alibaba-admin 对应 |
|---|---|---|
| 智能体资产管理 | 应用与版本管理 | `application`, `application_version`, `agent_schema` |
| 工作流编排与执行 | DAG、节点执行器、调度 | `WorkflowExecuteManager`, `ExecuteProcessor` 体系 |
| 智能体运行分派 | 基础/工作流策略分派 | `AgentServiceImpl`, `AgentExecutor` |
| 模型管理 | provider+model 分层 | `provider`, `model`, `ModelFactory` |
| 知识库 | kb/document/chunk 链路 | `knowledge_base`, `document`, RAG 索引处理 |
| 工具管理 | 工具生命周期 | `plugin`, `tool`, schema/config 管理 |
| MCP 纳管 | MCP Server 管理 | `mcp_server` |
| 观测治理 | Trace/Service/Overview | `ObservabilityController`, tracing repository |
| 账号权限基础 | 账号/工作空间/APIKey | `account`, `workspace`, `api_key` |

## 3. 复用优先级建议

### 高优先级直接借鉴
- 应用/智能体版本化建模。
- 工作流定义+版本+节点+边建模。
- 运行时任务状态机与步骤记录。
- 知识库、工具、MCP 资产管理表。
- 观测日志与审计的链路追踪字段（`trace_id/request_id/task_id`）。

### 中优先级借鉴后改造
- 并发与高可用相关模型（按你们生产部署方式细化）。
- 统计报表汇总表（按实际 BI 维度调整）。

### 低优先级/暂缓
- 评测域（dataset/evaluator/experiment）可在后续引入。
- Prompt 独立域可先并入智能体配置快照。
