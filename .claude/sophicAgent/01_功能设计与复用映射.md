# SophicAgent 功能设计与复用映射

## 1. 当前功能设计（依据系统设计说明书 4~8 章）

### 1.1 智能体管理子系统
- 通用智能体管理：分类、查询、详情、定义加载、版本查询。
- 专用智能体管理：按业务场景管理，支持运行配置加载。

### 1.2 设计器子系统
- 工作流编排：顺序/分支/并发/重试/回退，产出可执行定义。
- 智能体配置：模型策略、工具绑定、知识源绑定、记忆策略、I/O 参数配置与校验。

### 1.3 运行时子系统
- 环境感知：接收事件、解析上下文、授权校验、路由到智能体。
- 智能决策：生成执行计划、选择候选工具、输出决策、校验高风险动作。
- 任务执行：执行计划/步骤，调用工具与工作流，知识检索，状态保存与恢复。
- 协同调度：任务提交、优先级调度、资源分配、并发控制、队列查询、任务取消。

### 1.4 能力组件子系统
- 工作流引擎：流程装载、执行、挂起/恢复/终止、状态查询、版本发布。
- 知识库：导入、索引、检索（RAG/GraphRAG）、权限校验。
- 工具：注册、发现、调试、部署、调用、REST 转 MCP 适配。
- 记忆管理：短期/长期/工作记忆读写、恢复、清理。

### 1.5 框架治理子系统
- 运维监控：指标采集、运行状态、资源使用、告警与历史。
- 日志审计：调用日志、审计事件、调用链追踪、审计归档。
- 调用统计：按用户/业务/模型/工具维度统计并产出报表。
- 权限安全：权限校验、数据访问策略、脱敏、高危动作拦截、角色授权。
- 异常容错：异常处理、重试、切换备用模型、恢复、故障处理查询。
- 高并发：限流、排队、并发配额、超载拒绝。
- 高可用：健康检查、主备切换、故障接管、服务恢复。
- 部署集成：部署计划、配置加载/更新、外部系统集成、接入点注册。

## 2. 复用映射（基于 spring-ai-alibaba-admin）

| SophicAgent 模块 | 可复用能力 | spring-ai-alibaba-admin 对应 |
|---|---|---|
| 智能体资产管理 | 应用与版本管理 | `application`, `application_version`, `agent_schema` |
| 工作流编排与执行 | DAG、节点执行器、调度 | `WorkflowExecuteManager`, `ExecuteProcessor` 体系 |
| 智能体运行分派 | 基础/工作流策略分派 | `AgentServiceImpl`, `AgentExecutor` |
| 模型管理 | provider+model 分层 | `provider`, `model`, `ModelFactory` |
| 知识库 | kb/document/chunk 链路 | `knowledge_base`, `document`, RAG 索引处理 |
| 工具管理 | 工具生命周期 | `plugin`, `tool`, schema/config 管理 |
| MCP 纳管 | MCP Server 管理 | `mcp_server` |
| 观测治理 | Trace/Service/Overview | `ObservabilityController`, tracing repository |
| 账号权限基础 | 账号/工作空间/APIKey | `account`, `workspace`, `api_key` |

## 3. 复用优先级建议

### 高优先级直接借鉴
- 应用/智能体版本化建模。
- 工作流定义+版本+节点+边建模。
- 运行时任务状态机与步骤记录。
- 知识库、工具、MCP 资产管理表。
- 观测日志与审计的链路追踪字段（`trace_id/request_id/task_id`）。

### 中优先级借鉴后改造
- 并发与高可用相关模型（按你们生产部署方式细化）。
- 统计报表汇总表（按实际 BI 维度调整）。

### 低优先级/暂缓
- 评测域（dataset/evaluator/experiment）可在后续引入。
- Prompt 独立域可先并入智能体配置快照。
